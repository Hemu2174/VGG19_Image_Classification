# ── Why each version was chosen ──────────────────────────────────────────────
#
# torch==2.10.0 + torchvision==0.25.0
#   Unchanged from previous working state. These are the confirmed
#   torch 2.10 GA release (Jan 22 2026) paired versions with cp314
#   Linux CPU wheels on PyPI.
#
# Pillow==11.2.1
#   Root cause of prior failure: Pillow 10.4.0 was released Oct 2024,
#   before Python 3.14's ABI was finalised (Oct 7 2025). It has no
#   cp314 wheel. pip fell back to the sdist, which requires zlib headers
#   unavailable on Streamlit Cloud's build environment.
#   Fix: Pillow 11.0.0 (Oct 2025) was the first release to ship cp314
#   manylinux wheels. 11.2.1 (Apr 2026) is the latest 11.x stable release
#   and ships cp314-cp314-manylinux_2_28_x86_64.whl on PyPI.
#   API used in app.py (Image.open, Image.verify, image.convert,
#   UnidentifiedImageError) is unchanged across Pillow 10→11→12.
#
# pandas==3.0.2
#   Root cause of prior failure: pandas 2.2.3 was released Aug 2024,
#   before Python 3.14's ABI was stable. No cp314 wheel exists for it.
#   pip fell back to the sdist, which requires a C compiler toolchain
#   and Cython not present on Streamlit Cloud's build environment.
#   Fix: pandas 3.0.0 (Jan 21 2026) was the first release to declare
#   Python 3.14 support and ship cp314 manylinux wheels.
#   3.0.2 (Mar 30 2026) is used as it includes regression fixes.
#   Requires-Python >=3.11, compatible with Python 3.14.8.
#   API used in app.py (pd.DataFrame, .rename, .apply, .set_index) is
#   stable across pandas 2.x and 3.x with no breaking changes for this
#   usage pattern.
#
# streamlit==1.40.2
#   Pure Python wheel (py3-none-any). No binary compilation required.
#   Compatible with Python 3.14. Unchanged.
#
# ── Final dependency matrix ───────────────────────────────────────────────────
# Package       Version   cp314 Linux wheel   Source

# streamlit     1.40.2    py3 (pure Python)   PyPI
# torch         2.10.0    cp314 ✓             PyPI (GA Jan 2026)
